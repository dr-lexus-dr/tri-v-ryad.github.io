# Самоцветы — игра «три в ряд» для Яндекс Игр

HTML5-игра на чистом JavaScript: 8×8 поле, каскады, цели по цветам, ограничение ходов,
лидерборд, облачные сохранения, реклама и локализация ru/en. Без внешних ассетов:
графика рисуется на canvas, звук синтезируется через WebAudio, поэтому архив весит
несколько десятков килобайт и не требует интернета, кроме самого SDK.

## Структура

```
index.html          разметка экранов (меню, игра, оверлеи)
css/style.css       оформление, мобильная и альбомная вёрстка
js/main.js          состояние приложения, экраны, ввод, сохранения
js/game.js          правила уровня: ходы, цели, каскады, победа/поражение
js/board.js         поле: поиск совпадений, гравитация, подсказки, перемешивание
js/render.js        отрисовка поля, анимации, частицы
js/platform.js      обёртка Yandex Games SDK
js/i18n.js          строки ru/en
js/audio.js         синтезированные звуки
assets/icon.svg     иконка/favicon
```

## Локальный запуск

ES-модули не работают через `file://`, нужен любой статический сервер:

```bash
python3 -m http.server 8765
# открыть http://127.0.0.1:8765/index.html
```

Без SDK игра запускается в «локальном режиме»: прогресс пишется в `localStorage`,
реклама пропускается, таблица лидеров показывает заглушку. Для отладки состояния
откройте `index.html?debug=1` — в `window.__gems` будут объекты `game`, `renderer`, `save`.

## Публикация на GitHub Pages

Проект готов к деплою как статический сайт: все пути относительные, `index.html`
лежит в корне, а workflow `.github/workflows/pages.yml` собирает площадку и
убирает из неё тег SDK (вне Яндекс Игр он не нужен).

```bash
git init
git add .
git commit -m "Gems match-3 game"
git branch -M main
git remote add origin https://github.com/USER/REPO.git
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
После первого запуска workflow игра будет доступна по адресу
`https://USER.github.io/REPO/` (для пользовательского репозитория — `https://USER.github.io/`).

Что работает на Pages: сама игра, уровни, сохранение прогресса в `localStorage`,
звук, пауза, перемешивание. Реклама, облачные сохранения и таблица лидеров
доступны только внутри Яндекс Игр, поэтому кнопка «Лидеры» в демо-режиме
скрывается автоматически. Проверить интеграцию SDK локально можно с параметром
`sdk=1`: `http://127.0.0.1:8765/index.html?sdk=1`.

## Сборка архива для консоли разработчика

```bash
zip -r gems.zip index.html css js assets -x "*.DS_Store"
```

`index.html` должен лежать в корне архива. Загрузите файл в
[консоли разработчика Яндекс Игр](https://games.yandex.ru/console/) → «Загрузить игру».

## Настройка в консоли

0. **Черновик игры.** Включите «Игра использует облачные сохранения» (п. 1.11 требований),
   «Монетизация» (п. 1.12), выберите поддерживаемые платформы и ориентации, заполните
   «Как играть», «Об игре» и «Версию». Название в черновике должно совпадать с названием
   в игре и быть уникальным в каталоге; иконка и обложка — не скриншоты, без рамок
   и скруглённых углов.

1. **Таблица лидеров.** Создайте лидерборд с техническим именем `totalScore`
   (тип — «больше лучше», сортировка по убыванию, целые числа). Игра отправляет
   накопленные очки игрока: `ysdk.leaderboards.setLeaderboardScore('totalScore', score)`.
   Если имя другое — поменяйте `LEADERBOARD_ID` в `js/platform.js`.
2. **Реклама.** В разделе монетизации включите полноэкранную и rewarded-рекламу.
   Полноэкранная показывается только после победы и не чаще раза в 60 секунд,
   начиная с третьего уровня. Rewarded — по кнопке «+5 ходов» на экране поражения;
   если реклама не загрузилась, ходы всё равно выдаются.
3. **Иконка и скриншоты** загружаются отдельно в карточке игры (512×512 и кадры 16:9).

## Что уже интегрировано из SDK

- SDK подключается тегом `<script src="https://yandex.ru/games/sdk/v2">` в `index.html`,
  как требует документация; `YaGames.init()` вызывается с ожиданием загрузки, и если SDK
  не ответил, игра стартует в локальном режиме.
- `features.LoadingAPI.ready()` — вызывается после загрузки интерфейса.
- `features.GameplayAPI.start()/stop()` — на старте уровня, паузе, победе, поражении и в меню.
- `adv.showFullscreenAdv()` — межстраничная реклама с кулдауном 60 с; на время показа
  геймплей, звук и ввод ставятся на паузу.
- Остановка звука при потере фокуса окна и при возврате в игру.
- `adv.showRewardedVideo()` — «+5 ходов» с корректной обработкой `onRewarded`/`onError`.
- `player.getData()/setData()` — облачное сохранение прогресса (уровень, очки, звёзды, звук, язык),
  слияние с локальным по максимуму прогресса.
- `environment.i18n.lang` — язык интерфейса ru/en, переключатель в меню.
- `leaderboards` — таблица лидеров по накопленным очкам.

## Правила и баланс

- 8×8, 5 цветов до 5-го уровня, дальше 6.
- Ходы: 30 на первом уровне, уменьшаются на 1 каждые ~1.5 уровня, минимум 14.
- Цели: одна цель до 9-го уровня, две — дальше; количество считается от числа ходов,
  чтобы уровень оставался проходимым.
- Совпадение из 4 фишек даёт +30 очков, из 5 и больше — +60, каждый каскад умножает очки.
- Звёзды: 3 — осталось ≥40% ходов, 2 — ≥15%, иначе 1. Оставшиеся ходы дают бонус 50 очков.

- [ ] Реклама не показывается до первого действия игрока и чаще раза в минуту.
- [ ] Rewarded-реклама вызывается только по нажатию кнопки.
- [ ] Нет внешних ссылок и запрещённого контента.
- [ ] Проверены портретная и альбомная ориентации.
- [ ] В черновике включены облачные сохранения (п. 1.11) и монетизация (п. 1.12).
- [ ] Название в игре, в черновике и на промоматериалах совпадает (п. 5.1.3) и уникально (п. 5.12).
- [ ] Кнопка rewarded явно сообщает, что награда — за просмотр рекламы (п. 4.5.1).
- [ ] Иконка и обложка — не скриншоты, без рамок и скруглений (п. 5.6, 8.3.3).
