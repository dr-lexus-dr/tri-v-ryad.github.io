## О проекте

«Самоцветы» — головоломка, в которой нужно менять местами соседние фишки и собирать
ряды из трёх и более одинаковых. Уровни строятся по формуле: растёт сложность, ходов
становится меньше, а целей — больше. За уровень даются звёзды, за оставшиеся ходы —
бонусные очки, общий счёт уходит в таблицу лидеров.

Игра написана на чистом JavaScript без фреймворков, сборщиков и внешних ассетов:
графика рисуется на Canvas 2D, звук синтезируется через WebAudio, весь архив весит
меньше 100 КБ и работает без интернета, кроме загрузки Yandex Games SDK.

## Возможности

- Поле 8×8, свайпы и выбор двух фишек тапами, каскадные совпадения.
- Бонусы за линии из 4 и 5 фишек, множитель за каждый каскад.
- Цели по цветам и лимит ходов, звёзды за прохождение, бонус за неиспользованные ходы.
- Перемешивание поля и подсказка после нескольких секунд без действий.
- Сохранение прогресса: `localStorage` и облако Яндекс Игр с слиянием по максимуму.
- Таблица лидеров по накопленным очкам.
- Реклама через SDK: межстраничная после победы и rewarded «+5 ходов» с фолбэком.
- Локализация на русский и английский, язык определяется через SDK и переключается вручную.
- Адаптивная вёрстка: портрет, альбомная ориентация, десктоп; пауза и отключение звука.

## Управление

| Действие | Как |
| --- | --- |
| Обменять фишки | Проведите пальцем или мышью к соседней клетке |
| Обменять тапами | Нажмите на фишку, затем на соседнюю |
| Пауза | Кнопка с двумя полосками в правом верхнем углу |
| Перемешать поле | Кнопка «Перемешать» под полем (один раз за уровень) |
| Звук | Кнопка динамика в меню и в паузе |

## Технологии

- JavaScript (ES-модули), без зависимостей и сборки.
- Canvas 2D для поля, анимаций и частиц; CSS для интерфейса и экранов.
- Web Audio API для коротких синтезированных звуков.
- Yandex Games SDK v2: реклама, лидерборд, облачные сохранения, язык, игровые события.
- GitHub Actions для публикации демо на GitHub Pages.

## Структура проекта

```
index.html                 разметка экранов и подключение SDK
css/style.css              оформление, адаптив, альбомная вёрстка
js/main.js                 состояние приложения, экраны, ввод, сохранения
js/game.js                 правила уровня: ходы, цели, каскады, победа и поражение
js/board.js                поле: совпадения, гравитация, подсказки, перемешивание
js/render.js               отрисовка поля, анимации, частицы
js/platform.js             обёртка Yandex Games SDK и демо-режим
js/i18n.js                 строки ru/en
js/audio.js                синтезированные звуки
assets/icon.svg            иконка и favicon
assets/screenshots/        скриншоты для README
```

`docs/` — локальные выписки из документации Яндекс Игр, в репозиторий не попадают.

## Локальный запуск

ES-модули не работают через `file://`, нужен статический сервер:

```bash
python3 -m http.server 8765
# открыть http://127.0.0.1:8765/index.html
```

- `?debug=1` — доступ к состоянию игры через `window.__gems` (`game`, `renderer`, `save`).
- `?sdk=1` — принудительно инициализировать Yandex SDK вне каталога (для проверки интеграции).

Без SDK игра работает в демо-режиме: прогресс пишется в `localStorage`, реклама
пропускается, кнопка «Лидеры» скрывается.

## Демо на GitHub Pages

Демо: **https://dr-lexus-dr.github.io/tri-v-ryad.github.io/**

Публикация уже настроена: workflow `.github/workflows/pages.yml` собирает `_site`
из файлов игры, убирает из копии тег SDK и выкладывает сайт. В репозитории нужно
только выбрать источник деплоя: **Settings → Pages → Build and deployment →
Source: GitHub Actions**.

В демо доступны сама игра, уровни, звук, пауза, перемешивание и сохранение прогресса
в браузере. Реклама, облачные сохранения и таблица лидеров работают только внутри
Яндекс Игр, поэтому в демо кнопка «Лидеры» скрыта.

## Сборка для Яндекс Игр

```bash
zip -r gems.zip index.html css js assets/icon.svg -x "*.DS_Store"
```

`index.html` должен лежать в корне архива. Полученный файл загружается в
[консоль разработчика Яндекс Игр](https://games.yandex.ru/console/) → «Загрузить игру».

Перед публикацией в черновике:

- включите «Игра использует облачные сохранения» и «Монетизация»;
- создайте лидерборд с техническим именем `totalScore` (больше — лучше);
- включите полноэкранную и rewarded-рекламу;
- заполните «Как играть», «Об игре», «Версию» и выберите платформы с ориентациями;
- проверьте, что название в игре, черновике и промоматериалах совпадает и уникально;
- загрузите иконку 512×512 и обложку — не скриншоты, без рамок и скруглений.

## Что интегрировано из SDK

- SDK подключается тегом `<script src="https://yandex.ru/games/sdk/v2">`; вне каталога
  (GitHub Pages, локальный сервер) инициализация пропускается.
- `LoadingAPI.ready()` — после загрузки интерфейса.
- `GameplayAPI.start()/stop()` — на старте уровня, паузе, победе, поражении и в меню.
- `adv.showFullscreenAdv()` — после победы, с кулдауном 60 секунд; звук, ввод и
  геймплей на время показа останавливаются.
- `adv.showRewardedVideo()` — «+5 ходов» на экране поражения; при ошибке рекламы
  ходы выдаются всё равно.
- `player.getData()/setData()` — облачный прогресс (уровень, очки, звёзды, звук, язык).
- `environment.i18n.lang` — язык интерфейса; ручной выбор игрока сохраняется.
- `leaderboards` — таблица лидеров по накопленным очкам.

## Правила и баланс

- Поле 8×8; 5 цветов до 5-го уровня, дальше 6.
- Ходы: 30 на первом уровне, уменьшаются на 1 каждые ~1,5 уровня, минимум 14.
- Цели: одна до 9-го уровня, две — дальше; количество считается от числа ходов.
- Линия из 4 фишек даёт +30 очков, из 5 и больше — +60; каскад умножает очки.
- Звёзды: 3 — осталось не меньше 40% ходов, 2 — не меньше 15%, иначе 1.
- Каждый оставшийся ход при победе приносит 50 очков.
